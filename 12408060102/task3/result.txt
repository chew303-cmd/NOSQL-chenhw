    第1名  demo:02            90 分

    第1名  Student:12408060102 92 分
    第2名  demo:02            90 分
    第3名  demo:01            85 分
本人更新后：分数 = 92，名次 = 第1名（降序位置 0）

== 5. 数据类型核验 =============================================================
键                            实际类型      选择理由
------------------------------------------------------------------------------------------------
exam:12408060102:student      hash          学生信息是多字段对象，Hash 可以按字段读写、保留其他字段
exam:12408060102:chapters     set           已完成章节需要去重且要判断成员是否存在，Set 天然唯一并支持集合运算
exam:12408060102:rank         zset          成绩需要按分数排序取前 N 名，Sorted Set 按 score 自动排序
exam:12408060102:session      string        会话标识是一个整体值，只需整体读写并配合过期时间
（会话键在过期前已检查过类型：TYPE = string；过期后再查会返回 none）
