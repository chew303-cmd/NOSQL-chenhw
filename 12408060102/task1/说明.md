# task1 MongoDB 课程信息查询与维护

## 文件
| 文件 | 作用 |
| --- | --- |
| `init_db.py` | 初始化：重建 `exam_12408060102.courses`，写入 3 门课程（与业务代码分开执行） |
| `task1.py` | 业务操作：查询 / 局部更新 / 幂等新增 / 核验，**可重复执行** |
| `out_init.txt` | 初始化输出 |
| `result.txt` | 业务操作输出（与报告截图一致） |

## 运行
```bash
python init_db.py
python task1.py
```

## 要点
1. **查询**：`$match` 过滤 teacher=张老师 且 status=OPEN，`$project` 里用 `$size: "$chapters"` 现算章节数量（不写死）。结果：命中 1 门，`COURSE-12408060102-01`，章节数 2。
2. **局部更新**：`update_one({"chapters.chapterId": "CH02"}, {"$set": {"chapters.$.title": ...}})`，用位置操作符 `$` 只改命中元素，其他字段与其他章节原样保留；返回 `matchedCount=1 / modifiedCount=1`。
3. **幂等新增**：筛选条件加 `"chapters.chapterId": {"$ne": "CH03"}` + `$push`，第一次 `modifiedCount=1`、第二次 `matchedCount=0`，CH03 只有 1 个；未删除再插入，也未整文档替换。
4. **核验**：CH02 标题 = `Redis基础与应用-2`、CH03 数量 = 1、章节总数 = 3、teacher/status 保持原值。
