# NOSQL-chenhw
本仓库是《NoSQL数据库》上机测验的提交，包含 task1 到 task4。task1 做 MongoDB 课程查询与局部更新，初始化和业务代码分开；task2 实现库存原子扣减与事务，覆盖正常、库存不足、中途异常回滚和连续购买四个场景；task3 用 Redis 完成学生 Hash、章节 Set、成绩排行榜和会话过期验证；task4 对比 Pipeline 与逐条写入的耗时，含尾批处理。环境为 Redis 三主三从 Cluster 加 MongoDB，客户端用 Python，连接信息未写入代码，学号参数集中定义。readme.txt 说明了运行环境、依赖和各题执行方法，结果均为实际运行输出
